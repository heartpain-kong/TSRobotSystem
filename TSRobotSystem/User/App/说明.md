# User/App 说明（应用层）

> **一句话**：**业务都在这里**。换机器人 = 只改这一层 + `robot/robot_def.h`。

---

## 1. 这一层管什么 / 不管什么

| 管 ✓ | 不管 ✗ |
|---|---|
| 任务（周期/优先级/栈）、决策、模式 | 寄存器/协议细节（Device 的事）|
| 机器人差异（几何参数、机构类型、电机分配）| HAL 调用（Bsp 的事）|
| 任务间数据流（`msg_center` 话题）| 数学推导（algorithm 的事）|

**依赖**：`App → Device / algorithm / Bsp / msg_center` ✓（App 之间**只通过话题**通信 ✗ 不许互相读全局变量 ✓）

## 4. 一个任务的"三要素"

```cpp
/* ① 周期/优先级/栈:写在 robot_def.h,不要写在源码里 */
#define XXX_TASK_PERIOD_MS      2u
#define XXX_TASK_PRIORITY       osPriorityNormal
#define XXX_TASK_STACK          2048u

/* ② 任务体:robot_task.cpp —— "跑一拍 + osDelayUntil(绝对时刻)" + 超时计数 */
static void start_xxx_task(void *argument)
{
    (void)argument;
    xxx_task_handle = osThreadGetId();
    uint32_t next = osKernelGetTickCount();
    for (;;)
    {
        uint64_t t0 = DWT_GetTimeline_us();
        Xxx_Task();                                   /* 跑一拍 */
        if ((uint32_t)(DWT_GetTimeline_us() - t0) > (XXX_TASK_PERIOD_MS * 1000u)) { xxx_task_overrun++; }
        next += XXX_TASK_PERIOD_MS;
        osDelayUntil(next);
    }
}

/* ③ 建任务:OSTaskInit() —— osThreadNew 返回值必须检查! */
```

**加一个任务的完整步骤**：见 `../代码架构框架.md` 第 5.4 节（含 CMake / 脚本清单 / `Robot_Init` 三处接线）✓

## 5. 坑

1. **App 之间不要互相 include 去读全局变量** ✗ —— 一律 `msg_center` 话题 ✓（否则改一处牵一片 ✓）
2. **同一路电机只能归一个任务** ✗ —— 分配宏集中在 `robot_def.h`（`CHASSIS_MOTOR_x` / `GIMBAL_MOTOR_*` / `HIGHRISE_MOTOR_*`，`0xFF` = 未分配 ✓）
3. **别把"谁推进设备"写两处** ✗ —— 例：`Rc_Task()` / `Referee_Task()` / `MiniPC_Task()` 都由 **`cmd`** 调 ✓
4. **日志落盘 `Log_Task()` 只能在一个任务里调** ✗（目前是 `robot`）—— 它和 `bsp_flash` 共用 W25Q64 状态机 ✓
5. **关键数据要写进 `Error_Get_Snapshot()`** ✓ —— 否则事后复盘没有"当时指令 vs 实际" ✓
6. **`osDelay` 会累积漂移** ✗ ⇒ 一律 `osDelayUntil(绝对时刻)` ✓
7. **RTOS 堆只有 32 KB** ✗ ⇒ 任务栈别乱开（`configTOTAL_HEAP_SIZE`）；`g_thread_create_failed > 0` 就是堆不够 ✓
