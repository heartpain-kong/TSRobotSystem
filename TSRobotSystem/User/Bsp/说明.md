# User/Bsp 说明（板级外设层）

> **一句话**：把 CubeMX 生成的 HAL 包成"好用、好用错"的接口。**不含任何业务**。

---

## 1. 这一层管什么 / 不管什么

| 管 ✓ | 不管 ✗ |
|---|---|
| 外设初始化、收发、超时 | "底盘/云台/模式"这类业务词 |
| DMA/中断/回调的注册与分发 | 谁该发什么帧、什么时候发 |
| 单位换算到"人话"（mV、rpm、µs）| 任务、消息、错误码 |
| 对外提供简单函数 | 直接操作别的层 |

**依赖方向**：`Bsp → HAL/CubeMX` ✓（**不许**反过来依赖 Device/App ✗）

---

## 2. 现有模块

| 模块 | 作用 | 主要入口（细节见同名 `.h` / `.md`）|
|---|---|---|
| `rc` | **DBUS 遥控帧接收**（UART5 100000 8E1，协议层：只解帧，不含在线判定）| `BSP_RC_Init()`、`BSP_RC_Get()`、`BSP_RC_Get_Rx_Count()` |
| `uart` | 串口接收引擎：**DBM + IDLE** 收整帧 + DMA 发 | `USART_init(huart, 回调)`、`USART_RX485_init[_Ex]()`、`UART_Transmit_Data()` |
| `spi` | SPI 阻塞/中断/DMA 收发 | `BSP_SPI_Init()`、`BSP_SPI_Transmit[_Receive][_DMA/_IT]()` |
| `ospi` | OCTOSPI（外部 Flash 用）：命令/自动轮询/DMA | `BSP_OSPI_Init()`、`BSP_OSPI_Is_Ready()` + 三种回调 |
| `adc` | ADC 校准 + 循环 DMA 采样 + 换算 mV/温度 | `BSP_ADC_Init(hadc, 采样点数)`、`BSP_ADC_Get_Mv[_Average]()`、`BSP_ADC_Get_Temperature()`、`BSP_ADC_Bind_ADC3()` |
| `pwm` | 定时器 PWM：频率/占空比 | `BSP_PWM_Init()`、`BSP_PWM_Set_Freq/_Set_Duty()`、`BSP_PWM_Start/Stop()` |
| `gpio` | GPIO 读写/翻转/多脚同写 | `BSP_GPIO_Write()/Toggle()/Write_Multi()` |
| `fdcan` | CAN/FDCAN：过滤器 + 发送 + 接收回调 | `can_filter_init()`、`bsp_can_init(hfdcan, 回调)`、`fdcan_send_data_stand/Exten[_wait]()` |
| `flash` | **外部 8MB QSPI Flash 存储层**（分区、按页/扇区自动拆分）| `Flash_Init/Read/Write/Erase/Is_Blank/Get_Jedec_Id()` |
| `power` | 板载电源：**PC15 5V 使能** + **电压检测** | `Power_5V_Enable/Is_Enabled()`、`Power_Voltage_Init()`、`Power_Task()`、`Power_Get_Voltage()`、`Power_Is_Under/Over_Voltage()` |
| `timestamp` | **TIM5 1MHz 自由计数**做长时间戳（**无中断**）| `Timestamp_Init(&htim5)`、`Timestamp_Get_Us32/_Get_Ms()`、`Timestamp_Update()` |
| `dwt` | 内核周期计数器：短延时 + 性能测量 | `DWT_Init()`、`DWT_Delay()`、`DWT_GetTimeline_us()` |
| `usb` | **（预留）** USB 方面的 BSP 封装位置 | —— |

### 两个时间基准的分工（别混用 ✗）
* `dwt`：**短延时**、**任务耗时/超时计数**（1 计数 = 1 内核周期）
* `timestamp`：**超时判定、限速、调度**（µs 粒度、跨回绕安全、不占 NVIC）

## 3. 怎么加一个 Bsp 模块

1. `User/Bsp/<名>/bsp_<名>.{h,cpp,md}`（从 `User/模板/bsp_template.*.tpl` 复制，去掉 `.tpl`）
2. 头文件：保护宏 + `extern "C"`（C 侧要 include 的话）+ 简单函数
3. 只做外设本身的事；参数**不要**在这里写死业务值 ✗
4. `CMakeLists.txt` + `CMakeLists_template.txt` 的 include 列表加目录
5. `tools/cubemx_post_export.ps1` 的 §5 清单加一条
6. 在 `Robot_Init()` 里按依赖顺序初始化

## 4. 坑（真踩过的）

1. **CubeMX 是引脚/外设参数的唯一真源** ✓ —— 别在代码里悄悄改（改了就重跑导出脚本 ✓）；`.ioc` 里的参数才是"设计意图"
2. **BDMA 只能访问 D3 SRAM（0x38000000）** ✗ —— 给 BDMA 用的缓冲（如 `ws2812_buffer`）必须放 `.RAM_D3` 段，否则 DMA 读不到、现象是"什么都没发生"
3. **DMA + D-Cache**：发送前 `SCB_CleanDCache_by_Addr()` ✓；接收缓冲要么放非缓存区、要么 clean/invalidate ✓
4. **一个串口只能注册一种接收回调** ✗（`USART_init` 会覆盖 ✓）
5. **`Flash_*` 写一页约 0.4 ms 且阻塞** ✗ ⇒ 绝不要在 1 kHz 控制任务里直接写 ✓；而且它内部会"泵" `W25Q64_Task()` ⇒ **只能在同一个任务里用** ✓
6. `bsp_flash` 是**外部 Flash**（W25Q64）✓，别和芯片内部 Flash 搞混 ✗
