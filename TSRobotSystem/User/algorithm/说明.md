# User/algorithm 说明（纯算法层）

> **一句话**：**只吃数字、只吐数字**。不碰任何硬件，所以能被单独测试、能被搬到别的工程。

---

## 1. 这一层管什么 / 不管什么

| 管 ✓ | 不管 ✗ |
|---|---|
| 数学与模型：滤波、解算、限幅、转换 | `HAL_*`、`hspi1`、`__disable_irq`、GPIO ✗ |
| 纯函数 / 纯类（输入参数 → 输出）| 任务、消息、调度 |
| 常量（`inline constexpr`）| 从哪拿数据、算完给谁 |

**依赖**：只能依赖 `math_support`、CMSIS-DSP（`arm_math.h`）✓，**不许**依赖 Bsp/Device/App ✗

---

## 2. 现有模块

| 模块 | 内容 | 关键接口 |
|---|---|---|
| `PID` | 通用 PID | `class Class_PID`（`Init`/`Calculate`/`Clear`…）|
| `Kalman` | ① 通用卡尔曼框架 ② **四元数 EKF（姿态解算）** | `class Class_Kalman`；`class Class_QuaternionEKF : public Class_Kalman`（`Init(Q1,Q2,R,λ,lpf)`、`Update(gx,gy,gz,ax,ay,az,dt)`、`Get_*_Rad()`、`Get_YawTotalAngle_Rad()`）|
| `chassis_control` | **底盘解算**：麦轮 `Class_chassis_M4` + 舵轮 `Class_chassis_D4` + 2舵轮2全向 `Class_chassis_D2Q2` | `Init(a,b,r,装配表)`、`count_run1/count_run2()`（反解）、`forward_count()`（正解里程计）、`Set_Top_Yaw()` |
| `math_support` | 角度/限幅/转换/矩阵 + 通用常量（**一个目录一份 md**）| `Math_Angle_Wrap_2Pi/Wrap_Pi/Diff_Pi/Abs_Diff`、`LimitMax/LimitMinMax`、`uint_to_float/float_to_uint_*`、`math_matrix_*`、`PI2`/`MATH_RPM_TO_RADPS`/`MATH_DEG_TO_RAD` |
| `crc` | 校验 | `crc32_mpeg2()`、`crc_ccitt()`、`crc8()`（裁判系统/miniPC 协议用）|

## 3. 写法约定

* 有状态的用 `class Class_XXX` ✓：`Init()` 配置 → `Cout()/Update()/Calculate()` 算一拍 → `Get_XXX()`
* **一行的 getter/setter 一律 `inline` 写在头文件末尾** ✓（别在 .cpp 里堆三行小函数）
* 成员默认 `protected` ✓，只把真需要的开成 `public`
* 纯量/常量用 `inline constexpr` ✓（C++17，头文件里一份，不需要 .cpp 定义）
* **单位写进注释**：rad / rad·s⁻¹ / m / m·s⁻¹ / N·m ✓
* **移植别人的算法**（如官方 EKF、参考工程 PID）：
  * 保留原有的**数学结构、参数含义、变量名含义** ✓（只改命名/格式）
  * md 里写清「移植自哪里、改了什么、哪些参数是官方调好的」✓
  * 已知的"看着奇怪但故意的"地方要**原位保留 + 注释说明** ✓（例：四元数 EKF 里 `temp_vector.pData[3] = 0.0f` 是"不修正 yaw 轴数据"，官方与参考工程都这样 ✓）

---

## 4. 怎么加一个算法

1. `User/algorithm/<名>/alg_<名>.{h,cpp,md}`（从 `User/模板/algorithm_template.*.tpl` 复制）
2. 头文件尽量自包含；需要数学就 `#include "math_support.h"` / `#include "arm_math.h"`
3. 写清单位、参数含义、取值范围 ✓
4. `CMakeLists*.txt` include 列表 + `tools\cubemx_post_export.ps1` §5 清单
5. 在 App 层实例化使用（**算法层不放实例** ✓，实例放使用它的 App 模块里）

---

## 5. 坑

1. **别在算法里做单位换算的"最后一公里"** ✗ —— 例：`Class_chassis_M4::Get_Speed()` 输出 **rpm** ✓，转 rad/s 由 `motor_task` 统一做 ✓（换算只有一处 ✓）
2. **`acos/asin` 等要防定义域** ✗ —— 输入 clamp 到 [-1,1]（参考工程和官方都有这个坑 ✓）
3. **除零**：任何"除以模长/除以 dt"的地方都要判 0 ✓
4. **CMSIS-DSP 矩阵接口用的是 `arm_matrix_instance_f32`**，要指向**定长数组** ✓（本工程不用 malloc ✓）
5. **算法层不要有 static 全局状态** ✗（要状态就用类实例，实例归 App 层持有 ✓）
