# 舵轮(D4)与舵向定义

> 对应代码:`alg_chassis_control.h/.cpp` 的 `Class_chassis_D4`
> 装配配置:`App/chassis/chassis_task.cpp` 的 `s_d4_steer[]`

---

## 1. 两种转向电机的区别

| | 以前:GM6020 直驱 | 现在:3508 屁股 + 外部 1:4 |
|---|---|---|
电机侧→轮侧总减速比 | **1.0** | **4.0**(屁股 1:1 × 外部 1:4)|
轮子转 1 圈,电机转 | 1 圈 | **4 圈** |
关节侧扭矩常数 | ≈0.4 N·m/A(6020 自身) | **0.0625 N·m/A**(0.0156 × 4)|
20 A 时舵向轴扭矩 | ≈8 N·m | **≈1.25 N·m** ⚠️ |

> ⚠️ 力矩只有原来的约 1/6 ⇒ 装车后重点验证**静止状态下能不能把轮子拧到位**。
> 不够就加大外部减速比(1:8 / 1:10),或提高限幅。

## 2. 减速比在哪里生效(只在一处 ✓)

```
chassis_task.cpp : dj_motor.Set_Gearbox_Rate(4.0f)      ← 唯一赋值点
        ↓
motor_DJ.cpp     : Now_Pos = Total_Encoder/8192 × 2π / Gearbox_Rate   ← ÷4
                   Now_W   = rpm × π/30 / Gearbox_Rate                ← ÷4
                   Now_T   = 电流 × 扭矩常数 × Gearbox_Rate            ← ×4
```

- **电机层出口已经是"轮侧(关节侧)"值** ⇒ 上层(chassis、算法)拿到的就是轮子角度 ✓
- `chassis_D_steer_def.reduce_ratio` 只是**配置记录**，**不参与运算**
- ❌ **绝对不要**在 chassis 里再除一次 4 ⇒ 否则变成 1:16，角度全错、电机只转 1/4 圈

**核对方法**:手转轮子一圈，`motor_task_get_now_pos()` 应变化 **6.283 rad**。
只变 1.57 ⇒ 多除一次;变 25.1 ⇒ 少除一次。

## 3. 舵向定义结构体

```c
struct chassis_D_steer_def
{
    uint8_t motor_index;                    /* 舵向电机在电机注册表的下标，0xFF = 不驱动 */
    Enum_Chassis_Steer_Ratio reduce_ratio;  /* 总减速比预设(仅记录,不参与运算) */
    fp32    dir;                            /* 装配方向:+1 / -1(电机正转时轮子反着转就填 -1) */
    fp32    seat_offset;                    /* 零位偏移 [rad](配合 PE2 光电找零) */
};
```

减速比预设来自 `alg_chassis_control.h`：

```c
enum Enum_Chassis_Steer_Ratio
{
    CHASSIS_STEER_RATIO_6020_DIRECT   = 1,   /* 6020 直驱 */
    CHASSIS_STEER_RATIO_3508BARE_1TO4 = 4,   /* 3508 屁股 1:1 × 外部 1:4 */
};
```

> 需要数值(日志/调试)时用 `Chassis_Steer_Ratio_To_Fp32()`。
> 原装 3508 + 1:4 的 76.8 目前不是预设；需要时往枚举里加一项，或把该字段改成 `fp32`。

实车配置(`chassis_task.cpp`):只有 0 号轮装了舵向，其余填 `0xFF`。

## 4. 2π→0 的映射(为什么必须归一)

**问题**:电机侧角度来自 `Total_Encoder`，是**多圈连续值**(可能 7.5 rad、-12 rad)。
直接用会在 `0` 与 `2π` 交界处出现"差一整圈"的假跳变 ⇒ 舵向猛甩、来回抽动。

**解决**:

```c
Motor_To_Seat()  = Math_Angle_Wrap_2Pi(dir × motor_rad + seat_offset)
```

⇒ 轮侧角度永远是 `[0, 2π)`，`Get_Seat()` / `Set_Seat_Now()` 都在这一个域里比较 ✓

> 另:位置环 PID 用 `Math_Angle_Diff_Pi` 取最短夹角(`Class_PID_Angle`),
> 也是同一件事 —— 只不过发生在**误差层**而不是**换层**。

## 5. 优劣弧的选择(两层分工)

| 层 | 函数 | 做什么 |
|---|---|---|
运动学层 | `count_run1()` | 矢量方向与当前角差 **> 90°** ⇒ 目标角 **翻转 180°** + **轮速取反**(优弧)|
执行层 | `Seat_To_Motor_Delta()` | 返回 **最短带符号夹角** ⇒ 电机不绕远路 |

阈值宏(集中在头文件开头):

```c
#define CHASSIS_D_FLIP_THRESH    (PI / 2.0f)   /* > 90° 翻转 */
#define CHASSIS_D_READY_THRESH   (PI / 4.0f)   /* 残差 ≥ 45° 先不给驱动速度 */
```

**为什么执行层返回"增量"而不是绝对角**:

```
绝对角: target = dir × (seat - offset)
        ⇒ 多圈值被 Wrap 折回后，可能反向转一整圈 ✗

增量:   target = 当前电机角 + Seat_To_Motor_Delta()
        ⇒ 永远走最短弧、永不被折回、天然抗 2π→0 ✓
```

## 6. 典型用法

```c
/* 每拍 */
float seat_now = s_d4.Motor_To_Seat(i, motor_task_get_now_pos(steer_idx));
s_d4.Set_Seat_Now(i, seat_now);                       /* 喂实测角 */

float seat_cmd = s_d4.Get_Seat(i);                    /* 反解目标角 */
float motor_tgt = motor_task_get_now_pos(steer_idx)
                + s_d4.Seat_To_Motor_Delta(i, seat_cmd);   /* 最短弧增量 */
motor_task_set_mit(steer_idx, motor_tgt, 0, 0, kp, kd);
```

> 上电第一拍 `seat_now = 0`，所以**先喂一次 `Set_Seat_Now` 再算增量**，否则最短弧会按"当前角 0"判断。

## 7. 上板自检

| 检查 | 期望 |
|---|---|
手转轮子 1 圈 | `Get_Now_pos()` 变化 **6.283 rad** ✓ |
`Get_Seat()` | 始终 ∈ `[0, 2π)` ✓ |
连续给同一目标 | `Seat_To_Motor_Delta()` 收敛到 **0** ✓ |
目标跨 0/2π 边界 | 电机**反向小角度**修正，不绕整圈 ✓ |
`dir = -1` 的轮子 | 电机正转时轮子反转 ✓ |
