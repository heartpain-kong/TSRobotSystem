# 本轮变更说明（汇总）

> 一句话 ✓：外部 Flash / 日志 / 上电链**全部修好** ✓，系统现在**零错误码空跑** ✓。
> 细节排查过程见 [`Bsp/flash/待办_Flash.md`](Bsp/flash/待办_Flash.md)（12 节 ✓）。

## 1. 外部 Flash（W25Q64）—— 修好了 ✓

**根因**：无数据命令（`0x06` 写使能 / `0x20` 擦除）用了 `DataMode = DATA_1_LINE` ✗
⇒ HAL 以为还要传数据 ⇒ 状态卡在 `BUSY_INDIRECT_WRITE` ⇒ 后续全部 `HAL_BUSY` ✗
⇒ 改成 **`HAL_OSPI_DATA_NONE`**（官方例程写法 ✓）后一次通过 ✓。

本轮共修 **10 个 bug**（详见待办文档）：字节序 ×2、DMA 读、不 Abort、多余软复位、
WEL 回读、手写轮询、`DataMode`、`rx_done_flag`、CRC 布局。

| 开关（`User/Bsp/flash/bsp_flash.h`）| 值 | 含义 |
|---|---|---|
`FLASH_ENABLE` | **1** ✓ | 使用外部 Flash（日志 ✓）|
`FLASH_SELFTEST` | **0** ✓ | 上电四步自测（排查时才开 ✓ 会多擦一次扇区 ✓）|

## 6. 加速度偶发全 0 —— 自愈 ✓

`User/Device/bmi088/dev_bmi088.cpp`：

* 根因：`ACC_CONF` 写在 `ACC_PWR_CTRL` 之后**太早**（手册要求 ≥5 ms ✓）⇒ `odr=0` ⇒ 数据恒 0 ✗
* 修法：加 **`HAL_Delay(10)`** ✓ + 写后**回读校验** ✓
* 再加**自愈** ✓：连续 **500 次**读到三轴全 0 ⇒ 自动重配一次 ✓

## 8. 上位机（`E:\rm\上位机接收器`）

* **自动匹配已改为"扫描全部串口 + 每个口并行试所有波特率"** ✓
  * 之前是**串行** ✗（N 个口 × 4.8 s ⇒ 口多时很慢 ✗）
  * 现在每个端口一个线程 ✓ ⇒ 总耗时 ≈ **最长单口**（约 5 s）✓
  * 日志会先打印**扫到哪些口** ✓
  * 去掉了硬编码的 `COM3` 占位 ✓（现在是空 ✓）
* 异常会**写进日志面板** ✓（不再静默失败 ✗）
* 自动匹配**不会重复进入** ✓（点多次只提示 ✓）
* 未接板子时会明确提示 `端口不存在` ✓
