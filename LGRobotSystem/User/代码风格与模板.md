# 代码风格与模板

> 目标：**任何人写的代码，看起来像同一个人写的。**
> 配套：`代码架构框架.md`（结构怎么搭）、`User/模板/`（直接复制用的骨架）。

---

## 1. 命名

| 对象 | 规则 | 例子 |
|---|---|---|
| 文件 | `<层前缀>_<模块>.{h,cpp,md}` | `bsp_adc.h`、`dev_rc.cpp`、`chassis_task.h` |
| 头文件保护宏 | `<全大写文件>` | `DEV_RC_H`、`CHASSIS_TASK_H` |
| 类 | `Class_<名字>` | `Class_PID`、`Class_Kalman`、`Class_Motor_DM` |
| 结构体 / 枚举类型 | `Struct_xxx` 或 `<域>_xxx` / `Enum_xxx` | `Struct_send_motor`、`chassis_M_wheel_init`、`Enum_Msg_Topic` |
| 函数 | `大驼峰`，域前缀 | `BMI088_Get_Gyro()`、`Msg_Publish()`、`Rc_Is_Online()` |
| 类的方法 | `大驼峰`：动词/属性 | `Init()`、`Cout()`、`Update()`、`Get_Speed()`、`Set_Pos()` |
| 局部/成员变量 | `下划线` 小写 | `wheel_speed`、`send_data`、`s_ref`（static）|
| 函数参数 | 双下划线开头 | `void Set_Pos(const fp32 __pos);` |
| 宏 | 全大写 + 域前缀 | `MSG_SLOT_SIZE`、`RC_LOST_TIMEOUT_MS`、`CHASSIS_HALF_A` |
| 全局调试量（供调试器看）| `volatile` + 小写下划线 | `volatile bool bmi088_init_ok` |
| 文件级 static 状态 | `s_` 前缀 | `static uint32_t s_rx_len;` |

**类型**：项目里统一用 `struct_typedef.h` 的 `fp32`/`fp64`；C 侧用 `bool`（`<stdbool.h>`）、`uint8_t/32_t`（`<stdint.h>`）✓

## 2. 文件骨架

### 2.1 头文件
```c
/* ============================================================================
 * xxx.h — 一句话说清"这是什么"
 * 说明 / 用法 / 坑 见同目录 xxx.md
 * ========================================================================== */

#ifndef XXX_H
#define XXX_H

#include <stdbool.h>
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

/* ---- 可配置宏(★ = 需要按实车改的) ---- */
#define XXX_DEFAULT_PERIOD_MS   10u

/**
 * @brief 初始化
 * @return true = 成功
 */
bool Xxx_Init(void);

#ifdef __cplusplus
}
#endif

#endif // XXX_H
```

### 2.2 源文件
```cpp
//
// xxx.cpp — 一句话说清"这是什么"
// 说明 / 用法 / 坑 见同目录 xxx.md
//

#include "xxx.h"

#include "bsp_timestamp.h"      /* 依赖项按"自己的头 → 别人的头 → 系统头"排 */
#include "msg_center.h"

#include <string.h>

static_assert(sizeof(Xxx_Data_t) <= MSG_SLOT_SIZE, "Xxx_Data_t 超过 MSG_SLOT_SIZE");
```

### 2.3 md（**必须写**）
参考 `User/模板/task_template.md.tpl`，至少包含：
1. **一句话定位** + 在数据流里的位置（画个小图）
2. 每拍做什么（编号步骤）
3. API 表
4. ★ 参数表（哪些要按实车改）
5. **坑**（写你踩过的，别写废话）
6. **上板自检**（不写这节的 md 不合格 ✗）

## 3. 注释约定（重要）

**代码里只留三样** ✓：
1. 文件头 **3~4 行**：标题 + "说明见同目录 xxx.md"
2. 函数上方 **1~2 行**：`@brief`（必要再加 `@param/@return`）
3. **少量"为什么"** 的行内注释 —— 只写**非显然**的坑（例：`/* BDMA 只能访问 D3 SRAM ⇒ 缓冲必须放 .RAM_D3 */`）

**其余全部写进 md** ✓：背景、设计理由、API 表、错误码表、排错顺序、上板自检。
> 判断标准：**"读代码的人不看注释也能看懂代码；看不懂的是'为什么这么设计' —— 那去 md。"**

⚠️ 写块注释时**不要在 `/* */` 里再写 `/* */`** ✗ —— 注释会提前闭合，后面全被当代码（这个坑真踩过 ✓）

## 4. 类的写法（C++ 模块）

```cpp
class Class_XXX
{
public:
    void Init(/* 配置 */);
    void Cout(/* 输入 */);            /* 主计算函数:命名按语义 Cout/Update/Calculate */
    fp32 Get_Result() const;

protected:                             /* ★ 成员默认 protected,只把需要的开成 public */
    /* ---- 初始化相关常量 ---- */
    fp32 r = 0.0f;
    /* ---- 内部变量 ---- */
    fp32 state = 0.0f;
    /* ---- 读写变量 ---- */
    fp32 result = 0.0f;
};

/* ---- 简单取值/置值一律 inline 写在头文件末尾 ---- */
inline fp32 Class_XXX::Get_Result() const { return result; }
```

* **成员默认 `protected`** ✓（只有确实要外部访问的才 `public`）
* 成员按 `初始化相关常量 / 常量 / 内部变量 / 读变量 / 写变量 / 读写变量` 分组，每组一句注释 ✓
* **一行的 getter/setter 全部 `inline` 放头文件底部** ✓（别在 .cpp 里写一堆三行函数）
* 类里**不要** `malloc`/`new` ✗（嵌入式静态分配）
* 移植别人的算法时：**保留原有的数学结构和参数含义** ✓，只改命名/格式 ✓，并在 md 里写清"移植自哪里、改了什么" ✓

## 5. 单位约定（不统一会出人命）

| 环节 | 单位 |
|---|---|
| 姿态/角度 | **rad**（对外、快照、话题一律 rad ✓）|
| 角速度 | **rad/s** |
| 距离/速度 | **m**、**m/s** |
| 力矩 | **N·m** |
| **电机接口**（`Set_Pos/Set_W/Set_T`、`Get_Now_*`）| **关节侧** rad / rad·s⁻¹ / N·m ✓（各品牌内部换算减速比 ✓）|
| **底盘算法**（`Class_chassis_M4::Get_Speed`）| **rpm** ✓ |
| 电机 ↔ 底盘 | 换算**只在** `motor_task_set/get_wheel_rpm()` 里做一次 ✓（`MATH_RPM_TO_RADPS`）|

## 6. C / C++ 边界

* `main.c` / `freertos.c` / `usbd_cdc_if.c` 是 **C** ⇒ 只能 include 带 `extern "C"` 的**纯声明头** ✓（如 `robot.h`、`motor_task.h`）✗ 不能 include 出 C++ 类的头 ✓
* 给 C 调用的函数定义写成 `extern "C" void Xxx_Init(void)` ✓（头里已 `extern "C"` 的话,定义可省 ✓,写了更醒目 ✓）
* 头文件里**不要**出现 C++ 独有的东西（`class`、`nullptr`、引用参数 `&`）✗

## 7. 模板文件怎么用（`User/模板/`）

| 模板 | 用途 |
|---|---|
| `bsp_template.h.tpl` / `.cpp.tpl` | 加一个 Bsp 外设模块 |
| `device_template.h.tpl` / `.cpp.tpl` | 加一个 Device 设备（含"中断只搬运 / 任务里组帧 / 发布话题"的标准骨架）|
| `algorithm_template.h.tpl` / `.cpp.tpl` | 加一个纯算法 |
| `task_template.h.tpl` / `.cpp.tpl` | 加一个 App 任务（含每拍 + `Msg_Publish` + 错误位 + 快照骨架）|
| `*.md.tpl` | 对应的说明文档骨架 |

**用法**：复制到目标目录 → **去掉 `.tpl` 后缀** → 全局把 `xxx` / `XXX` / `Xxx` 换成你的模块名 → 按 `代码架构框架.md` 第 5 节接进 CMake/脚本/`Robot_Init`/`OSTaskInit` ✓
> `.tpl` 后缀是故意的 ✓ —— 这样模板文件**不会被编译** ✗，不会污染固件 ✓
