# cmd_485 — 上/下 MCU 链路（USART2 RS485，500 Hz，一发一回）

文件：`cmd_485.h` / `cmd_485.cpp`，由 `Cmd_Init()` 注册、`Cmd_Task()` 每拍调用（**500 Hz**）。
帧格式沿用 miniPC 虚拟串口协议。

---

## 1. 物理层

| 项 | 值 |
|---|---|
| 串口 | **USART2**（PD5=TX / PD6=RX，**PD4=DE**，HAL 硬件管理方向） |
| 波特率 | 4 Mbps（两边一致即可） |
| 格式 | 8N1，RS485 半双工 |
| 任务 | CMD 任务 500 Hz（`CMD_TASK_PERIOD_MS = 2`） |

---

## 2. 帧格式（固定 54 字节）

```text
[0]      0xA5
[1]      channel<<6 | mode
[2]      data_len = 48
[3..26]  半帧 A：命令（上->下）/ 反馈（下->上）        24 B
[27..50] 半帧 B：调试文本分片                          24 B
[51..52] CRC16（小端；reflected 0x8408，init 0，覆盖 [0..50]）
[53]     0x5A
```

| channel | 方向 | 半帧 A | 半帧 B | 频率 |
|---|---|---|---|---|
| `0` | 上 → 下 | 底盘命令（`MiniPC_Cmd_Payload_t`） | 下行调试分片 | 500 Hz |
| `1` | 下 → 上 | 反馈（`Cmd485_Feedback_t`） | 上行调试分片 | 500 Hz（一收一发） |

`mode` 位：

* 通道 0（命令）：`bit0` 使能、`bit1` 小陀螺、`bit2..6` 下行调试有效字节数（0..24）；
* 通道 1（反馈）：`bit0..5` 上行调试有效字节数（0..24）。

> 命令/反馈和调试分片装在**同一帧**里 ⇒ 500 Hz 一发一回，同时双向调试各 24 B/帧 ≈ **12 KB/s**，
> 不会互相抢帧位。

---

## 3. 半双工：请求-应答

* **上 MCU（master）**：每 2 ms 发一帧命令（带下行调试分片）；
* **下 MCU（slave）**：收到命令帧后**立刻**回一帧反馈（带上行调试分片），
  在接收中断里发，保证赶在上板下一次命令前。

---

## 4. 调试数据透传（双向）

* **上 → 下**：上板调试串口收到的字节（PC 的 `0x5C` 调参帧）压进下行缓冲，随命令帧下发；
  下板收齐后塞进自己的调试命令环形缓冲 ⇒ 一条串口线就能给下板调参。
* **下 → 上**：下板把要查看的 JSON 行（10 Hz，关掉本地串口 TX）压进上行缓冲，随反馈帧上传；
  上板按 `'\n'` 拼回整行，加 **`[L] `** 前缀从调试串口打出来；上板自己的 JSON 行带 **`[U] `** 前缀。

```text
[U] [LOG] JSON {...}      ← 上 MCU 自己的数据
[L] [LOG] JSON {...}      ← 下 MCU 透传上来的数据
```

整行上限 1280 B（下板一行 JSON 约 1045 B）；缓冲不够整行丢弃（`Cmd_485_Relay_Drop` 计数）。

---

## 5. 调试遥测

| 字段 | 含义 |
|---|---|
| `link.rx` | 上板收到的合法帧数（≈500/s）|
| `link.ch` | 下板最近一帧的 channel（0=命令）|
| `link.vx/vy/w` | 上板：下板反馈的 mm/s、mrad/s |
| `relay.used` | 上板透传缓冲里的字节数 |
| `relay.drop` | 透传整行丢弃计数 |
| `relay.tx` | 成功转发出去的 `[L]` 行数 |

---

## 6. 坑

1. 帧定长 54 B：`USART_RX485_init_Ex` 的 `recv_len` 必须等于 `CMD485_FRAME_LEN`；
   `RS485_recv_Data_N_MAX` 必须 ≥ 54（现为 64）。
2. 半双工方向：反馈/调试不要在任务里发（会和下一帧命令撞车），统一在接收中断里回。
3. CRC 覆盖 `[0 .. 50]`（不含 CRC 自身和帧尾）。
4. 掉线判定 100 ms：`Cmd_485_Get_Chassis/Get_Feedback` 超时返回 false。
5. 下板调试串口 TX 已关闭（`DEBUG_UART_TX_ENABLE = ROBOT_UPPER_ONLY`），数据只走 485。

---

## 7. 上板自检

```
① 两边烧同一版本（各自 robot_def.h 的 ROBOT_UPPER_ONLY 不同）
② 上板：link.rx 约 500/s、link.vx/vy/w 跟随下板里程计
③ 上板串口：自己的行带 [U]，下板数据带 [L]，relay.drop 保持 0
④ 遥控器在线后推杆，下板 m201/m203 跟随
⑤ 拔掉 A/B 线：link.rx 停止增长；下板 100ms 后回 IDLE
```
